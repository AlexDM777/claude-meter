# Выпуск новой версии

1. Обновите `AppUpdate.CurrentVersion` в `source/AppUpdate.cs`, номер интерфейса и номер установщика.
2. Выполните `source/build.ps1` и проверки `--self-test`, `--custom-test`, `--update-test`, `--ui-test`.
3. Выполните `release.ps1 -Version 1.0.0`, подставив новую версию. Скрипт проверяет совпадение версии с кодом.
4. Зафиксируйте исходники в GitHub. Создайте стабильный Release с тегом `v1.0.0` на нужном коммите.
5. Прикрепите все четыре файла из `dist`: Portable ZIP, Setup EXE, **ClaudeMeter-update-win-x64.zip**, SHA256SUMS.txt.
6. Опубликуйте Release (не draft и не prerelease). Нельзя заменять пакет в существующем теге: для исправления выпускайте новый номер.

Клиенты читают `/repos/AlexDM777/claude-meter/releases/latest`, сравнивают версии и выбирают строго `ClaudeMeter-update-win-x64.zip`. SHA-256 берётся из `digest` актива GitHub. Без корректной суммы автоматическая установка не запускается. Пакет содержит `update-manifest.json` с хешами каждого файла. Менять имя пакета обновления нельзя; номер задаёт тег и манифест.

Пользовательские настройки и авторизация находятся в `%LOCALAPPDATA%/ClaudeMeter`, отдельно от файлов приложения; в релизы их не добавлять.
